# Architecture map

Start with the
[`Federated Research Organism Doctrine v1`](federated-research-organism-doctrine-v1.md).
It defines the static ownership map and separates the human “scientific brain”
metaphor from authority.

Then read [`SYSTEM-ATLAS.md`](../../SYSTEM-ATLAS.md) for the compact generated
SRL-local entry and cell model. It is not current federation runtime evidence.
Its `D0_D1_spool_packet` values describe inactive legacy SRL adapter transport,
not the target Dual wire. Generated views do not replace native bootstrap,
health or release receipts.

## Responsibility summary

```text
SRL reasons.
Target doctrine: Dual transports and orders; current deployment is unproven.
Security owns Security truth and safety verdicts; neither grants execution.
Market owns market truth.
Each native domain alone admits and records its effects.
No global sovereign writer or global A2 authority exists.
```

| Contour | Owns | Must not claim |
|---|---|---|
| SRL | Scientific semantics, planning, bounded computation, proof, knowledge and scientific receipts | Domain truth, native effects or global authority |
| Dual | Target cross-domain wire order and delivery mechanics | Scientific meaning, validation or domain truth |
| Market | Market truth, gates, admission and native writers | Security truth or global transport ownership |
| Security | Security truth, safety, admission and native writers | General scientific planning or Market truth |
| CrossLab | Pager-only wake notification | Evidence, queue truth, execution or authority |
