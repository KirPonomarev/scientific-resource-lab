# A08 Native Algebra And SMT

V3.7 A08 activates external native executables for algebra, number theory,
groups, polynomial computation, and a second SMT solver contour. These tools
are not Python dependencies, are not vendored into SRL, and are not admitted
through `uv.lock`.

## Toolchain Boundary

The executable surface is `srl.packs.adapters.native_algebra`. It uses fixed
subprocess command vectors with no shell, bounded stdin payloads, short
timeouts, and a minimal environment. A tool reaches `ACTIVE` only when all of
these are true:

- executable found on `PATH`;
- version probe completes;
- bounded scientific smoke completes;
- independent crosscheck is recorded.

The gate is `scripts/checks/srf-v37-a08-gate.py`.

## Smokes

| Component | Executable | Smoke | Crosscheck |
|---|---:|---|---|
| `pari-gp` | `gp` | `83*97`, `znorder(Mod(3,7))` | integer product `8051`, order `6 = phi(7)` |
| `maxima` | `maxima` | factor `x^4 - 1` | expand factors back to `x^4 - 1` |
| `gap` | `gap` | group generated by `(1,2,3)` and `(1,2)` | size `6`, non-abelian `S3` |
| `singular` | `Singular` | factor `x^2 - y^2`; Groebner basis | factors `x-y`, `x+y`; basis output present |
| `z3-native` | `z3` | QF_LIA bounded integer SMT-LIB formula | unique witness exists by inspection |
| `cvc5` | `cvc5` | same QF_LIA SMT-LIB formula | agreement with native Z3 on `sat` |

## License Boundary

The A08 CAS tools are external operator/toolchain executables. Their licenses
are recorded in smoke evidence for visibility, but they are not redistributed
by SRL and must not appear in `uv.lock` or the Python dependency license
inventory.

The active license boundary is:

```text
external native executable; not vendored and not in uv.lock
```

This preserves the repository's Apache-2.0-compatible Python dependency
closure while allowing a local or CI runner to execute GPL-family CAS binaries
as independent programs.

## CI

The `v37-activation` workflow installs A08 native tools only in the dedicated
A08 job:

```bash
sudo apt-get install -y --no-install-recommends pari-gp maxima gap singular cvc5 z3
uv run python scripts/checks/srf-v37-a08-gate.py
```

No other job depends on these executables.
