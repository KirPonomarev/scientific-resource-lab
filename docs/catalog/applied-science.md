# Applied Science Packs

A13 activates bounded applied-science workloads and records broader wishlist
packages as formal replacements for v2.0.0 rather than unresolved software
waits.

ACTIVE under A13 runtime evidence:

- ripser
- pyriemann
- CVXPY
- native analytic Bayesian conjugate diagnostic
- native causal backdoor identification and falsification

FORMALLY_REPLACED for v2.0.0:

- GUDHI, geomstats, POT, pymanopt, KeplerMapper, TopoNetX, Regina
- PyMC, ArviZ
- DoWhy, Tigramite, EconML
- JAXopt, BoTorch

The replacement policy is evidence-bound: ripser covers persistent homology with
a null-control topology workload, pyriemann covers SPD geometry diagnostics,
CVXPY covers the bounded solver/license matrix, native conjugate Bayes covers
analytic posterior diagnostics without fake MCMC convergence claims, and native
backdoor causal checking covers identification plus falsification.

Applied result receipts require assumptions, diagnostics and solver status. A
causal effect cannot carry an estimate unless identification is established, and
no applied result grants authority, canonical writes or automatic scientific
promotion.
