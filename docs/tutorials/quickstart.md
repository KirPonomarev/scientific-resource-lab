# Quickstart

This guide walks through the first five minutes with the Scientific Resource
Lab using only the **public synthetic fixtures** in `fixtures/public/`. No real
data, credentials, or proprietary sources are required.

## 1. Install the package

The repository uses [uv](https://docs.astral.sh/uv/) for dependency management.

```bash
uv sync
```

This installs the `srlab` package and its quality-toolchain dependencies. The
fixtures themselves are generated by a standard-library script, so you can also
inspect them without installing anything.

## 2. Check the environment

`srlab doctor` prints a `DoctorReport/v1` and exits `0` when the environment is
healthy:

```bash
uv run srlab doctor
```

Expected output looks like:

```json
{"platform":"...","python":"3.12.x","schema_version":"DoctorReport/v1","srl_version":"1.0.1","status":"ok"}
```

## 3. Regenerate the synthetic fixtures

The public corpus is fully deterministic. Regenerate it to confirm the generator
works on your machine:

```bash
python3 fixtures/public/generate.py all
```

After the command runs, `fixtures/public/` contains canonical JSON artifacts:
`series-*.json`, `cloud-*.json`, `spd-*.json`, `claim-*.json`, `MANIFEST.json`,
and `README.md`.

## 4. Schema-validate a synthetic claim

Pick any synthetic claim and validate it against the packaged
`ScientificClaim/v1` schema. The synthetic claim is designed to be
schema-shaped and self-contained, so it validates without requiring any external
corpus or live system.

```bash
uv run python - <<'PY'
import json
from pathlib import Path
from srl.contracts.schema import validate

claim = json.loads(Path("fixtures/public/claim-00.json").read_text())
validate(claim, "ScientificClaim")
print("claim-00.json validates against ScientificClaim/v1")
PY
```

You can repeat the same check for the other five claims, the envelope
exercises in `first-claim.md`, or any synthetic fixture you create.

## 5. What is happening here?

- The fixtures are **fully synthetic**: every number, point, matrix, and claim
  was produced by `generate.py` from a fixed seed (`20260728`).
- The output is **canonical JSON**: sorted keys, compact separators, and a
  trailing newline, so identity checks and diffs are deterministic.
- The license is **CC0-1.0**: you can redistribute, modify, and use the corpus
  for any purpose without attribution.
